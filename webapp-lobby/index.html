Help

How to Play

Build mathematical expressions from cards to hit target numbers. First to reach the win score wins!

Game Flow

  • Host a room → other players join with the 4-digit code
  • Or enable "Simulate Player 2 (Bot)" for single-player
  • Customize rules: hand size, timer, operators, special cards
  • All players click Ready → host clicks Start

Controls

  • H — Host room
  • R — Toggle ready
  • S — Start game (host only)
  • ESC — Leave / Close help
  • ? — Toggle help
